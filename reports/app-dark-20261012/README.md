# 전체 화면 다크 모드 추가 조사 및 수정

기준: main 35b4d2bf99b3e1ecebd6b71c258384f07c446e53 (v97). 운영 theme 파일과 기준 파일 바이트 일치 확인.

## 원인과 수정

공통 테마의 customOverrides는 어두운 중성/갈색 변수만 변환한다. 인물·이야기의 --gbl-navy (#172c46), 묵상의 --gmd-ink/--gmd-muted/--gmd-navy, 찾기/성경선택/하단 선택의 파란색 변수는 그대로 남는다. 배경은 어둡게 변환되어 글자가 안 보인다. 인물·이야기 제목에서 기존 대비 2:1 미만을 DOM/CSS로 재현했다. 사용자 스크린샷의 상단 제목, 뒤로가기, 닫기, 인물 이름, 상세 소제목, 관련 이야기 링크와 같은 경로다.

js/gomna-theme.js의 수동 보완 CSS에 다크 모드 전용 변수 매핑을 추가했다. 이외 Reader의 회사 링크, 상단 보조 글자, 재생 표시 방식 설명의 대비도 보완했다. 운영 코드 변경은 이 파일만이다. 인증 처리, 저장 키 gomna_theme_v1, 내비게이션 이벤트, 본문 크기/줄간격, 이미지, 오디오 재생 코드, MP3/Cue, 서비스워커는 변경하지 않았다.

## 검증 한계 및 미리보기

위 검사는 DOM/CSS 모의검사다. 모든 실기기 화면, 이미지 위 대비, 가상 요소, 반투명 배경의 최종 합성, 실제 로그인/음원 재생, iPhone Safari/설치형 PWA 검증을 대신하지 않는다. 전체 앱 실기기 검증 완료로 표시하지 않는다. 최초 PWA 실행 불능 원인은 여전히 미확정.

scripts/preview-guide-theme.py로 최신 시험본을 실행한다. 인물/이야기/묵상/길잡이 URL을 출력한다. previewTheme=light로 라이트 확인. HTTP LAN은 Safari용이며 설치형 PWA에는 HTTPS 시험 주소가 필요하다.

추가 운영 배포는 아직 하지 않았다. 승인 후 테마 자산 참조 및 앱 코드 캐시 버전만 일관되게 갱신한다.
