# 인물·이야기 시대와 배경 편집 근거

확인일: 2026-09-28. 적용 범위: 인물 27명, 이야기 12편의 상세 화면.

- `history.era`, `history.place`, `history.text`는 모두 새로 쓴 한국어 요약이다.
- 연대는 책의 집필 시점이 아니라 등장인물·이야기의 배경을 설명한다.
- 족장 연대는 전통적인 배치이며 확정된 고고학 연도로 제시하지 않는다.
- 출애굽과 가나안 정착 연대는 견해 차이를 명시한다. 람세스 2세를 출애굽의 파라오로 확정하지 않는다.
- 사사 개개인의 정확한 연도를 임의로 만들지 않는다. 한나·사무엘은 왕정 이전/전환기의 대략적 배경이다.
- 다니엘의 이야기 배경과 책의 집필 연대를 구분한다. 메대 사람 다리오의 신원은 확정하지 않는다.
- 창조·노아 홍수에 계산된 단일 BC 연도를 붙이지 않는다.
- 세 비유는 실제 사건 연대 대신 예수님이 가르치시던 시대와 생활상을 설명한다.
- 현대 지명은 위치 이해를 위한 대략적 대응이다. 고대 국가 경계와 현대 국경이 같다는 뜻이 아니다.
- 요청에 따라 상세 화면 맨 아래의 소개/그림 안내 두 줄은 제거했다. 출처 검토 기록은 이 문서에 보관한다.
