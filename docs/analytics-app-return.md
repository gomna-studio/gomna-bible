# 은혜의말씀 다시 열기 확인법

`app_return_visit`은 이전 한국 날짜에 은혜의말씀 앱을 화면에 띄운 브라우저가 다른 한국 날짜에 홈·성경·묵상 중 하나를 다시 화면에 띄운 경우입니다. 앱 방문을 분리해서 보기 위한 보조 지표입니다.

- **GA4**: 이벤트 보고서에서 `app_return_visit` 행의 **총 사용자 수**를 봅니다. 이벤트 수를 사람 수로 쓰지 않습니다. 기존 **활성 사용자**, **재방문 사용자** 카드는 구글의 기존 집계 그대로입니다. 이 이벤트를 주요 이벤트로 지정하지 않습니다.
- **PostHog**: 같은 이벤트의 **Unique users**로, 프로젝트 보고 시간대를 확인하고 한국 날짜를 선택합니다. 두 서비스의 기기·브라우저 식별 방식이 달라 값이 정확히 일치할 필요는 없습니다.
- 적용 첫날은 기기에 숫자 하나(마지막으로 앱이 보였던 한국 날짜)만 저장합니다. 이전 날짜가 있는 경우에만 이벤트를 보냅니다. 새로운 사용자 ID·이메일·로그인 기록을 수집하지 않습니다. 예전 방문을 복원하지 않습니다.
- 검색 기사나 회사소개만 본 경우는 포함하지 않습니다. 열린 페이지가 백그라운드에만 있거나 화면을 밤새 그대로 켠 경우에도 날짜가 바뀌었다는 이유만으로 이벤트를 생성하지 않습니다.
- 저장한 날짜는 같은 브라우저·같은 사이트 저장공간에서만 이어집니다. 기기 변경, 저장공간 삭제, 비공개 창, 동의 거부, 내부·미리보기 제외, 추적 차단 등으로 일부 재방문은 측정할 수 없습니다. 동의가 철회되면 날짜 기록을 지웁니다. 설치형 웹앱의 저장공간은 브라우저와 구분될 수 있습니다.
