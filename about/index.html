ABOUT / GOMNA STUDIO

가능성을 발견하고,
경험으로 만듭니다.

01 — ABOUT US

Gomna Studio는 콘텐츠의 깊이와 기술의 가능성을 함께 살피는 스튜디오입니다. 아이디어의 출발점부터 사람이 마주하는 마지막 화면까지, 하나의 경험으로 설계합니다.

WHAT WE BUILD

내용의 가치를
경험의 가치로.

복잡한 자료에서 맥락을 찾고, 필요한 순간에 쉽게 만날 수 있도록 연결합니다.

대표 서비스 은혜의말씀에서는 성경 본문과 해설, 음성과 묵상을 하나의 흐름으로 구성했습니다. Gomna Studio는 콘텐츠와 사용자 사이에 필요한 길을 설계합니다.

HOW WE BUILD

우리가 중요하게
생각하는 것.

01

내용을 먼저 봅니다.

무엇을 전달할지, 어떤 맥락이 필요한지부터 살핍니다. 화면과 기능은 그 내용을 더 잘 이해하도록 돕는 역할을 합니다.

02

사용자의 흐름을 봅니다.

찾고, 읽고, 듣고, 다시 돌아오는 과정이 자연스럽도록 설계합니다. 기기와 화면이 달라져도 읽기 편한 경험을 지향합니다.

03

꾸준히 다듬습니다.

AI를 기획과 제작에 활용하고, 결과를 검토하며 개선합니다. 새로운 기술의 가능성을 사용자가 느끼는 변화로 이어갑니다.

THE NAME / GOMNA

서로 다른 가능성을
하나의 관점으로.

GOMNA라는 이름은 Google, OpenAI, Microsoft, NVIDIA, Anthropic의 이니셜에서 출발했습니다. 다양한 기술의 가능성을 이해하고, 독자적인 아이디어로 연결한다는 생각을 담고 있습니다.

회사명의 유래에 관한 설명이며, 해당 기업과의 제휴나 후원을 뜻하지 않습니다.
